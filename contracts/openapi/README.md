# OpenAPI Contracts

This directory contains machine-readable API contracts.

Current repository bootstrap includes the previously validated OpenAPI v1 baseline as:

- `openapi-v1.0.0.yaml`

The approved OpenAPI v1.1 offline extension is currently documented in:

- `docs/architecture/15-openapi-v1.1.md`

Before API implementation reaches production contract status, create the canonical additive v1.1 YAML here and validate it in CI. Do not invent or silently diverge from the approved markdown contract.
